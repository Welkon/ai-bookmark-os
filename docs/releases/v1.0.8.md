# AI Bookmark OS v1.0.8

本版本聚焦现有书签同步、访问计数、工作台加载和主动学习记录查看流程的完整性与稳定性。同步大量书签时会持续反馈进度并保留可用的旧列表，避免用户在等待期间误以为操作未生效。

## 书签同步进度与稳定性

- 全量书签同步会分阶段广播真实进度：读取书签树、整理数据、保存本地快照和完成状态均有明确反馈。
- 弹窗和完整工作台在同步期间展示进度、已处理数量和总数，保留上一次可用书签列表；同步完成后自动刷新完整快照。
- 增加同步操作序列与快照请求代次保护，阻止延迟的旧进度、旧列表或已失效操作覆盖最新状态。
- 同步失败状态可在发起页面和其他已打开页面正确提示，不再出现进度消失却没有结果说明的情况。

## 访问计数与工作台加载

- 统一书签访问计数的异步写入与校准逻辑，避免点击前后计数被不同数据源刷新为不一致的数值。
- 工作台优先渲染已缓存的书签内容，访问计数在后台异步批量校准，降低重新打开工作台时的空白等待。
- 计数刷新与书签同步相互隔离，避免大量书签同步时因额外全量读取拖慢主流程。

## 主动学习记录

- 主动学习相关记录页增加快捷搜索，可按记录内容快速筛选。
- 支持每页 10、20、50、100 条记录切换和分页浏览，避免大量记录只能连续滚动查看。
- 搜索、分页和记录操作后会自动校正当前页，保证列表状态与实际数据一致。

## 书签工作流与导航

- 加强书签检查、推荐、RSS 等既有异步流程的失败处理与任务调度，减少异常状态下的悬挂请求和不可用入口。
- 优化书签导航页面的现有交互与布局，保持桌面和窄屏下的操作入口可用。

- `npm run typecheck`：通过。
- `npm run build`、`npm run test:e2e`、`npm run preview:check`、`npm run audit:project`：通过。

## 安装

下载 `ai-bookmark-os-v1.0.8-chrome-extension.zip`，完整解压后，在 Chrome 的 `chrome://extensions` 页面开启开发者模式，选择直接包含 `manifest.json` 的解压根目录加载。
