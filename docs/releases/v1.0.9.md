# AI Bookmark OS v1.0.9

本版本修复扩展弹窗与完整工作台时间轴列表的展示问题。置顶书签不再影响日期分组的先后顺序，搜索结果恢复按相关度扁平展示并高亮关键词，滚动加载的书签保持在自己的日期分组内。

## 时间轴日期分组顺序

- 弹窗的日期分组此前由包含置顶书签的列表建立，置顶书签所属日期会被当成第一个分组，导致「今天」被更早的日期挤到后面。现在日期分组只由非置顶书签建立，置顶书签仍单独成组置顶展示。
- 弹窗与完整工作台的分组建立方式保持一致，分组内部依旧按当前排序（最新/最旧）排列。

## 搜索结果展示

- 弹窗渲染时会清空调用方刚计算出的搜索命中范围，导致搜索结果既不高亮关键词，也没有按相关度扁平展示，而是被重新按日期分组。现在命中范围由搜索流程统一维护，渲染不再覆盖。
- 搜索结果与热度排序同为扁平列表，弹窗与完整工作台均不再绘制时间轴竖线，避免出现与列表无关的悬空竖线。
- 在搜索或标签、置顶、重复视图下删除书签后，列表按当前筛选条件刷新，不再跳回全部书签。

## 滚动加载分组归属

- 时间轴按每页 50 条渐进渲染，跨页时若上一页停在某个日期分组中间，后续书签会脱离该分组容器直接挂到时间轴根节点。现在分页会续接上一页的分组容器，弹窗与完整工作台的分组层级保持完整。

## 验证

- `npm test`：51 项测试全部通过，新增弹窗时间轴分组顺序、搜索命中范围保留与分页分组续接的回归测试。
- `npm run typecheck`：通过。
- `npm run build`、`npm run test:e2e`、`npm run preview:check`、`npm run audit:project`：通过。

## 安装

下载 `ai-bookmark-os-v1.0.9-chrome-extension.zip`，完整解压后，在 Chrome 的 `chrome://extensions` 页面开启开发者模式，选择直接包含 `manifest.json` 的解压根目录加载。
